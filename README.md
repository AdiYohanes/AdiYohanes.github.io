## 👋 Tentang Saya

Saya seorang **Web Developer** yang juga berpengalaman sebagai **ERP Developer** — jembatan antara pengalaman web modern dan kekuatan enterprise ERP. Setiap baris kode ditulis untuk menyelesaikan masalah bisnis nyata.

Fokus saya:
- Membangun aplikasi web yang cepat, responsif, dan user-friendly
- Mengintegrasikan sistem enterprise (NetSuite) dengan ekosistem web modern
- Menciptakan solusi yang scalable dan maintainable

---

## 🛠️ Tech Stack

### Web Development
| Teknologi | Penggunaan |
|-----------|-----------|
| **React** | Frontend library untuk UI interaktif |
| **Next.js** | React framework dengan SSR & SSG |
| **Node.js** | Runtime untuk backend & tooling |
| **TypeScript** | Static typing untuk kode yang lebih aman |
| **PostgreSQL** | Relational database management |

### ERP & Enterprise
| Teknologi | Penggunaan |
|-----------|-----------|
| **NetSuite** | Cloud ERP platform |
| **SuiteScript** | Custom scripting for NetSuite |
| **RESTlets** | REST API endpoints di NetSuite |
| **Integration** | ETL, middleware, data sync |
